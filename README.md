# PalindromeCheckerApp
## Description
Palindrome Checker App is a Java application that checks whether a given word or sentence is a palindrome.

A palindrome is a word, phrase, or number that reads the same forward and backward.
Example: madam, racecar, 121
## Features
- Accepts user input
- Checks if the input is a palindrome
- Displays result (Palindrome / Not Palindrome)
- Simple and user-friendly interface
